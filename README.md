# Brightness Toggle 1.0.2

게임을 할 때 단축키 한 번으로 화면 밝기 프리셋을 전환하는 Windows용 프로그램입니다. C# + WinForms로 제작했으며, 트레이에서 계속 실행할 수 있습니다.

## 다운로드 및 실행

1. [v1.0.2 릴리스](https://github.com/idlepoe/brightness_toggle/releases/tag/v1.0.2)에서 **BrightnessToggle-1.0.2-win-x64.zip**을 다운로드합니다.
2. ZIP 파일을 원하는 폴더에 모두 압축 해제합니다.
3. **BrightnessToggle.exe**를 실행합니다.

Windows 10/11 64비트 PC용입니다. 설치 과정이나 Java/.NET 별도 설치가 필요 없으며 CMD 창도 열리지 않습니다. 배포 파일은 코드 서명되지 않았습니다.

## 빠른 사용법

1. 프로그램에서 밝기를 변경할 **대상 디스플레이**를 선택합니다.
2. 게임을 실행하고 **F9**를 한 번 누릅니다.
3. 기본 프리셋인 **default (0%) → +80% → default (0%)** 순서로 전환됩니다.
4. 화면 우측 하단에서 적용한 프리셋 이름과 밝기 보정량을 확인합니다. 표시는 약 2.2초 후 사라집니다.

F9를 길게 눌러도 연속 전환하지 않습니다. 기본 상태로 돌아가려면 **default (0%)**을 누르거나 단축키로 default까지 전환하세요.

## 프리셋 추가 및 미리 조정

1. **추가**를 눌러 프리셋을 만듭니다.
2. **프리셋 이름**에 원하는 이름을 입력합니다.
3. 슬라이더로 밝기 보정량을 **-50%~+100%** 사이에서 조정합니다.
4. **조정 시 바로 미리보기**가 켜져 있으면 화면에 즉시 반영됩니다. 끄면 설정만 저장됩니다.
5. **선택한 프리셋 적용**을 눌러 해당 프리셋으로 전환합니다.

목록에서 프리셋을 선택하는 동작은 편집 대상만 바꿉니다. F9와 **다음 프리셋** 버튼은 목록 순서대로 전환합니다. **삭제**로 불필요한 프리셋을 지울 수 있으며, default는 보정 0%의 원래 화면 프리셋이므로 편집하거나 삭제할 수 없습니다.

## 단축키 및 모니터

- **전환 단축키**에서 F1~F11 중 사용할 키를 선택합니다. 기본값은 F9입니다.
- 다른 프로그램이 이미 등록한 키는 사용할 수 없습니다. 충돌하면 다른 키를 선택하세요.
- **대상 디스플레이**에서 적용할 모니터를 선택합니다. 모니터를 바꾸면 이전 화면을 원래 상태로 복원합니다.
- 프리셋, 단축키, 모니터 선택은 자동 저장됩니다.

## 시스템 트레이 및 종료

**X를 누르면 종료되지 않고 시스템 트레이로 숨겨집니다.** 창 아래에도 이 안내가 표시됩니다.

- 작업 표시줄 오른쪽의 **노란 해 아이콘**을 찾으세요. 보이지 않으면 숨겨진 아이콘 메뉴(∧)를 확인하세요.
- 해 아이콘 **더블클릭**: 다음 프리셋.
- 해 아이콘 **우클릭 → 설정 열기**: 설정 창 표시.
- 해 아이콘 **우클릭 → default (0%)**: 보정 0%로 원래 화면 복원.
- 해 아이콘 **우클릭 → 종료 (원래 밝기 복원)**: 화면을 복원하고 완전히 종료.

X로 숨길 때도 안내 알림을 표시합니다. Windows 알림 설정에 따라 알림이 보이지 않을 수 있습니다. 프로그램을 강제 종료하면 원래 밝기 복원 코드가 실행되지 않을 수 있으므로 트레이 메뉴로 종료하세요.

## 밝기 보정 방식과 게임 호환성

이 프로그램은 **SDR 화면의 감마 보정**으로 어두운 중간 톤을 밝게 합니다. **+80%는 감마 보정 계수 1.8**를 의미하며, 모니터 백라이트나 물리적 휘도를 80% 높인다는 뜻은 아닙니다.

처음 보정할 때 읽은 모니터별 RGB 감마 테이블을 기준으로 계산하므로 여러 번 전환해도 보정이 누적되지 않습니다. default는 보정 0%인 원래 화면이며, 첫 번째 추가 프리셋은 +80%입니다. 정상 종료 시에도 원래 테이블을 복원합니다. 기존 default는 0%로 되돌리고, 기본 +25% 프리셋을 변경 없이 쓰던 경우 +80%로 갱신합니다. 직접 편집한 사용자 프리셋은 유지합니다. 표시되는 퍼센트는 모두 밝기 보정량입니다.

- 먼저 **SDR + 테두리 없는 창 모드**에서 확인하세요.
- HDR, 독점 전체 화면, 게임 자체 감마 처리에서는 효과가 없거나 다른 설정에 덮어써질 수 있습니다.
- 독점 전체 화면에서는 우측 하단 표시도 보이지 않을 수 있습니다.
- 야간 모드와 색상 보정 프로그램이 같은 화면 설정을 변경하면 충돌할 수 있습니다.
- 게임 프로세스에 코드를 삽입하지 않습니다.

프로그램은 API 호출 후 감마 테이블을 다시 읽어 확인합니다. 실패하면 오류를 표시하고 직전 상태 복원을 시도합니다. 이 확인은 특정 게임의 최종 화면까지 보장하지 않습니다. [Microsoft API 문서](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp)

## 문제 해결

| 증상 | 확인할 내용 |
|---|---|
| F9가 동작하지 않음 | 프로그램 실행 여부와 단축키 충돌 안내를 확인하고 다른 F키를 선택하세요. |
| 게임 화면이 변하지 않음 | 대상 모니터를 확인하고 SDR·테두리 없는 창 모드로 시험하세요. 게임이 감마를 덮어쓸 수도 있습니다. |
| X를 눌렀는데 계속 실행됨 | 정상 동작입니다. 트레이 우클릭 → 종료를 사용하세요. |
| 밝기 적용 또는 복원 실패 | 창의 오류 내용을 확인하고 HDR·그래픽 드라이버·다른 색상 보정 도구를 확인하세요. |

## 설정 파일

설정은 아래 위치에 자동 저장됩니다.

```text
%LOCALAPPDATA%\BrightnessToggle\settings.json
```

설정을 초기화하려면 프로그램을 정상 종료한 뒤 이 파일을 삭제하고 다시 실행하세요. Windows 로그인 시 자동 실행 등록은 포함하지 않습니다.

## 개발 및 검증

.NET 10 SDK가 필요합니다. 저장소 루트의 PowerShell에서 실행하세요.

```powershell
./scripts/build.ps1
./scripts/test.ps1
```

- 프로젝트: `src/BrightnessToggle.csproj`
- 빌드 결과: `publish/BrightnessToggle.exe` (Windows x64, 런타임 포함 단일 EXE)
- 테스트 결과: `TestResults/`

Release 빌드와 프리셋 순환·감마 수식·추가/삭제·적용 실패 시 상태 유지·트레이 숨김·종료 복원 호출·OSD 테스트를 확인했습니다. 테스트는 실제 화면을 변경하지 않는 백엔드를 사용합니다. 실제 감마 적용과 특정 게임의 호환성은 사용 환경에서 확인해야 합니다.

## 1.0.2 변경 사항

- default를 보정 0%(원래 화면)로 바로잡았습니다.
- 첫 번째 기본 추가 프리셋을 +25%에서 +80%로 변경했습니다.
- 목록, 현재 상태, 트레이, OSD의 퍼센트를 보정량으로 통일했습니다.
- 1.0.1 설정을 자동 변환하고, 프로그램명 대화상자 제목을 유지합니다.
