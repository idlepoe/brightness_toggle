# Brightness Toggle

C# / WinForms / .NET 10 기반 Windows x64 프로그램.

실행: publish/BrightnessToggle.exe. 배포 ZIP은 루트의 EXE 실행.
.NET 별도 설치 불필요. 콘솔 창 없음.

사용법
- 기본 프리셋: default, +25%.
- F9 한 번으로 다음 프리셋 순환. F1~F11 중 전환 키 선택 가능.
- 추가 버튼으로 프리셋 생성, 이름과 슬라이더(-50~+100%) 편집.
- 조정 시 바로 미리보기를 켜면 슬라이더 변경 즉시 적용. 끄면 편집만 저장.
- 목록 선택은 편집 대상을 변경. 선택한 프리셋 적용 버튼으로 적용.
- default는 수정/삭제 불가. 보정 전 원래 화면으로 복원.
- 전환 시 대상 모니터 우측 하단에 프리셋/보정량을 약 2.2초 표시.
- 대상 모니터를 변경하면 이전 화면을 복원.
- X는 트레이 숨김. 트레이 더블클릭은 다음 프리셋, 우클릭은 설정/복원/종료.
- 트레이 종료 메뉴로 완전 종료. 정상 종료 시 원래 화면 복원.

밝기 방식과 제한
SDR 감마 보정입니다. +25%는 감마 보정 계수 1.25이며 백라이트/물리 휘도 증가율이 아닙니다.
보정 전 RGB 테이블을 기준으로 계산하므로 반복 전환해도 누적되지 않습니다.
HDR, 독점 전체 화면, 게임 자체 감마 처리, 야간 모드/색상 보정 도구에 따라 제한되거나 덮어써질 수 있습니다.
먼저 SDR + 테두리 없는 창 모드에서 확인하세요. 독점 전체 화면에서는 OSD도 보이지 않을 수 있습니다.
게임 프로세스에 코드를 삽입하지 않습니다. 강제 종료 시에는 화면 복원 코드가 실행되지 않을 수 있습니다.
API 성공 후 테이블을 다시 읽어 확인하며, 실패 시 오류를 표시하고 직전 테이블 복원을 시도합니다.
테이블이 같아도 게임이 다른 출력 경로를 쓰면 실제 화면 변화까지 보장하지 않습니다.
API 문서: https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp

설정: %LOCALAPPDATA%/BrightnessToggle/settings.json
프리셋/단축키/모니터 자동 저장. 시작 시 밝기 변경 안 함. 자동 실행 등록은 포함하지 않음.

빌드: .NET 10 SDK에서 scripts/build.ps1 실행.
프로젝트: src/BrightnessToggle.csproj. 결과: publish/BrightnessToggle.exe.
테스트: scripts/test.ps1 실행.
Release 빌드 경고/오류 없음. 실제 화면을 변경하지 않는 백엔드로 프리셋 순환, 감마 수식,
추가/삭제, 적용 실패 시 상태 유지, 트레이 숨김, 종료 복원 호출, OSD 표시 테스트 통과.
실제 감마 변경, 물리 키 입력, 특정 게임의 호환성은 별도 확인이 필요합니다.

트레이 안내 업데이트
- 트레이/창/실행 파일 아이콘을 노란 해 모양으로 변경했습니다.
- 창 아래에 X를 누르면 트레이로 숨겨진다는 안내를 항상 표시합니다.
- X로 숨길 때 해 아이콘 위치와 설정/종료 방법을 알림으로 표시합니다. Windows 알림 설정에 따라 알림이 보이지 않을 수 있습니다.
