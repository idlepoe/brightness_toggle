# Privacy Policy for Brightness Toggle

Effective date: October 28, 2026

Brightness Toggle is a local Windows desktop utility for changing SDR gamma presets.

## Data collection

The application does not collect, transmit, sell, or share personal information. It has no user accounts, advertising, analytics, telemetry, or application-operated network services.

## Local settings

The application stores preset names, gamma correction amounts, the selected display identifier, and the configured hotkey in a local settings file. These settings remain on your device. Windows may redirect packaged application settings into its per-user package storage.

## Device access

The application accesses display gamma controls and registers a global preset-switching hotkey. It does not record general keyboard input, read game data, or inject code into games. Original gamma tables are kept in memory to restore the screen on normal exit.

## Deletion and control

Exit the application normally to restore the original gamma settings. You can delete the local settings file to reset the portable application, or uninstall the packaged app using Windows Settings. Local settings and installation details are described in the README.

## Third-party distribution

Microsoft Store and GitHub process downloads and account information under their own privacy policies. This policy describes the application itself.

## Contact

For privacy questions, open an issue at https://github.com/idlepoe/brightness_toggle/issues . Do not include personal or sensitive information in public issues.
